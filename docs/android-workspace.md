以桌面 `b5bea1c`（2026-10-15）的工作区同步为基线，继续对齐到 `38312b7` 的增量规范，采用 [工作区所有权](desktop-workspace.md)、[本地化](desktop-localization.md) 和 [界面术语](terminology.md) 中适用于安卓的约定。桌面 [CSS 规范](desktop-styles.md) 明确不包含 Android；移动端继续使用 React Native、Expo Router 和安卓原生刷新控件。

## 页面、账号与反馈

路由只携带项目、问题编号、完整提交 SHA、分支和路径等标识，不传已读取的数据、函数或恢复闭包。页面持有自己的数据与草稿。`SessionProvider` 按账号标识重建子树，避免另一账号看到前一账号保留的私有内容；设备语言和偏好位于账号边界之外。

返回页面时重新校验之前打开的分页窗口，读取过程中和失败时保留原有内容；显式下拉刷新将阅读窗口重置到第一页。`usePagedList`、`readListWindow` 和提交文件 reader 按稳定 ID 去重、在整窗读取成功后更新，并丢弃取消或失活请求的结果。详情页保留回复草稿、已展开内容及完成的操作结果。项目内切换栏目也保留修改记录筛选草稿、贡献表单和管理表单；贡献/管理面板首次访问后保留任务归属，隐藏时停止读取和反馈，已发送的写入继续持有原有互斥锁。删除操作的临时授权在面板失活时取消并清除。

`usePageFeedback` 为每次活跃访问提供 `capture()` 守卫。异步弹窗、提示和导航必须先检查守卫；切换页面或语言清除短暂反馈，保留草稿与操作结果。对话框随页面或语言变化关闭。下载及分析继续保留取消与底层任务收尾的约束。

## 修改记录与说明

项目修改记录支持分支选择和分页、分支搜索及文件路径过滤。提交详情使用完整 SHA 读取，展示按文件分页的差异、行号、截断提示和文件历史入口；未提供文字 patch 的文件不会伪造恢复代码。

“解释改动”先列出项目、提交、服务商、地址和模型，确认后才读取固定提交证据并发送。最多 100 个文件、单 patch 8000 字符，最终序列化后的证据 JSON 不超过 24000 字符（包含元数据和转义）。截断保持 JSON 完整且标记覆盖不全；代码、文件名和提交信息按不可信数据处理。切换提交或离开页面取消旧请求，AI 返回内容不替代用户决定。

## 程序审查

缺少受支持组件的合并请求会提示按需安装；删除文件、新增空文件和已有文字差异的文件不触发安装提醒。可永久关闭提醒，并从程序文件审查设置恢复。设置入口会展开组件管理并滚动定位到对应卡片，不自动下载组件或发送 AI。

启动时仅清理缓存中 `easyhub-analysis/{UUID}` 和 `easyhub-analysis-downloads/{UUID}.{ext}` 的异常退出残留，最多处理 32 个任务；不跟随顶层符号链接，内部链接只解除链接，递归深度和文件数量有界。用户保存的下载、原始选择文件、报告和已安装组件不属于该清理范围。原生串行队列与 `prepareAnalysisCache` 屏障保证清理先于新程序下载。

Java/Dalvik 与原生组件仍与桌面存放在同一个组件发行版，按需下载；本轮未新增移动端依赖，也未扩大安卓到本地源码项目或源码/发行版发布编辑功能。

## 桌面增量规范

启动验证失败区分离线、超时、权限受限、登录过期和安全存储故障。只有 GitHub 实际验证过的账号资料才随凭据保存在同一条安全存储记录；旧版仅含凭据的记录也能恢复。临时失败保留凭据，无身份缓存时显示恢复入口，不生成占位账号。恢复期间可重新连接、登录或打开设置；明确失效的授权不会继续用于工作区访问。

同账号重连保留客户端和已打开的分页窗口，并重新校验页面数据；退出、切号及迟到响应通过操作代次和存储写入队列隔离。刷新后的新凭据若暂时保存失败，保留内存状态并提示重试，不重复轮换已经失效的旧刷新凭据。

设置页的短暂成功反馈在折叠面板外显示，默认四秒后消失，也可手动关闭。触摸、鼠标悬停、键盘焦点、应用后台和屏幕阅读器暂停计时；重复操作重设期限，旧计时回调不能关闭新提示。错误和完整审查结果保留各自原有的生命周期。

待审查分组在异步数量大于零时默认展开，每个项目、待处理/已处理筛选保留独立的展开选择和分页窗口。手动收起不被刷新覆盖，一组读取失败不阻塞其他组；请求标题保持作者原文。

项目、问题、合并请求、发行版和修改记录的日期统一按应用中英文设置格式化，缺失或无效日期显示本地化说明。公开页面同样传入当前应用语言，不依赖设备语言。
