# EasyHub 界面用词

| 中文 | English | 用途 |
| --- | --- | --- |
| 发布源码 | Publish source code | 将选中的本地修改保存到 GitHub；首页与项目页使用同一个名称。 |
| 发行版 | Release | 可下载的发布内容和附件。 |
| 版本号 | Version number | 发行版的标识，例如 1.2.2。 |
| 修改记录 | Change history | 已提交的源码改动（commit），不称为“版本”。 |
| 下载当时的文件 | Download files at this point | 下载某条修改记录对应的源码。 |
| 合并请求 | Pull request | 提交给项目维护者的代码修改。 |
| 合并请求审查 | Pull request review | 查看文件、讨论和决定是否合入。 |
| 问题 | Issue | 项目中的问题与讨论。 |
| 获取最新 | Get latest changes | 将云端源码改动获取到本地。 |
| 查看修改 | View changes | 检查本地修改的文件。 |
| 重新读取 | Reload | 再次读取当前内容。 |
| 内容翻译 | Content translation | 翻译项目说明等用户内容。 |
| 界面语言 | Interface language | 切换 EasyHub 的界面文字。 |

“改进”“反馈”仅用于说明文字，不作为合并请求或问题的名称。
外观选项描述实际位置和样式，不使用“参考图”等设计稿用语。
