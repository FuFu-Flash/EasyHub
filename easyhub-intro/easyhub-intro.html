为什么做 EasyHub

GitHub 不该只有"懂的人"才用得好

命令行看不懂

add、commit、merge、rebase，一连串概念；一个报错信息就足以让人卡住，更不敢随便按回车。

选个文件夹、写句话、点一下就发布

官方客户端仍然复杂

GitHub Desktop 聚焦提交与分支，默认你理解仓库、暂存区；也不集中处理问题、项目下载这些日常操作。

首页式界面，操作像手机 App 一样直观

网页操作零散

看项目、下载 ZIP、回复问题、查历史版本，要在浏览器多个页面来回跳，下载断了也不知道进度。

一个窗口完成，下载带速度与剩余时间
核心特性

把日常用到的 GitHub 操作，都做成简单按钮

未登录时所有功能在演示模式中即可完整体验，数据只存在于当前窗口；登录后同样的界面切换为真实项目，访问令牌仅保存在 Windows 凭证管理器，全程直连、无自有服务器。

演示 / 真实双模式

不登录也能新建项目、发布更新、回复问题，只修改窗口内的演示数据并在重启后复原；登录后同样的界面操作真实 GitHub，先试后用不慌张。

本地文件夹发布源码

选择任意文件夹即可识别为项目；独立 Worker 扫描新增、修改、删除、重命名的文件，遵守 .gitignore、避开依赖目录，变化时防抖复检。基于 isomorphic-git，无需安装 Git。

冲突安全处理

发布前先检查云端：可安全衔接的更新自动先获取；双方改动同一文件时，双版本预览、逐个选择保留版本。复杂历史会阻止自动发布，绝不强制覆盖。

问题全流程管理

创建问题、回复评论、关闭与重新打开；问题列表按项目分组，从全局进入默认收起、从项目详情进入自动展开对应项目。

发布新版本 Release

正式版、Alpha、Beta 三种类型，自动建议并续号版本名；可插入链接与图片、选择多个下载文件，按 GitHub 公开限制校验（单文件小于 2 GiB、每版最多 1000 个、不可同名），随后真实创建 Release、逐个上传附件，已完成端到端验收。

公开内容翻译

一键统一翻译项目简介、README、问题与 Release 描述；README 按段落随滚动逐步翻译。私有项目不发送给第三方，项目名、版本号、文件名以占位符保护，译文本地缓存。

使用流程

四步，把本地改动发布到 GitHub

不需要命令行，也不需要事先理解分支、暂存区等概念。

步骤 01

选择本地文件夹

添加电脑上已有的文件夹并识别为项目，或把 GitHub 上的云端项目下载到指定位置。

步骤 02

自动检查改动

独立 Worker 扫描文件的新增、修改与删除，遵守 .gitignore 并避开常见依赖目录。

步骤 03

写说明、处理冲突

用一句话说明本次更新；若云端也有改动，逐文件对比并选择要保留的版本。

步骤 04

一键发布源码

自动先拉取可衔接的远端更新，再把本地改动安全同步到 GitHub，完成后可查看历史版本。

大多数 GitHub 工具默认你已经懂 Git。EasyHub 从第一次接触 GitHub 的人的视角出发：把操作做少、把话说直白、让新手不登录也能先练手。

为新手重新设计，而不是堆叠功能

GitHub Desktop、GitKraken 等工具默认用户理解提交与分支；OctoPunk 明确面向 power user；DevHub、Gitify 只解决通知。EasyHub 把日常操作收进一个首页——新建项目、看到改动、写一句话、点"发布更新"；演示模式让你不登录、不碰真实数据就能先学会。

一句话定位

EasyHub 不追求覆盖 GitHub 的全部功能，只追求让"记录创意、发布更新、管理项目"对普通人足够简单；免装 Git、中文界面与内容翻译都为这一个目标服务。对比基于各项目 2026 年 9 月公开资料整理。

开始使用

两种方式运行 EasyHub

Windows 安装版、便携版与演示版

在 Windows 上执行打包命令，生成安装版和便携版；演示版可单独打包。三者都无需安装 Git：

pnpm package:win
pnpm package:demo

输出位置：apps/desktop/release/EasyHub-1.0.0-setup.exe、EasyHub-1.0.0-portable.exe，以及 release/demo/EasyHub-1.0.0-demo.exe。未使用商业代码签名，首次运行 Windows 可能提示"未知发布者"。

从源码运行

环境要求：

  • Windows 系统
  • Node.js 22 或更高
  • pnpm 11 或更高
# 安装依赖并启动
pnpm install
pnpm dev

检查与构建

现有 66 项单元测试与界面点击测试，交付前可完整检查：

pnpm typecheck
pnpm lint
pnpm test
pnpm build

界面冒烟测试运行 pnpm test:ui。
