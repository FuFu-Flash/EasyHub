EasyHub macOS — SteamTools compatibility notice

EasyHub's Swift helper implements a local SOCKS5 and GitHub PAC service using
SteamTools public GitHub rules and DNSPod DNS-over-HTTPS. It preserves GitHub's
original TLS hostname validation. The helper source is supplied in this project
under GNU GPL version 3; the complete EasyHub license is bundled in LICENSE.
